## 2026-08-30 - Tooltips for Icon-Only Buttons in CustomTkinter Desktop Apps
**Learning:** Icon-only buttons (like `📸` or `🚀`) lack textual context for users, harming accessibility and intuitive usage. Adding a hover tooltip (`CTkToolTip`) provides screen reader / hover context without altering desktop layout constraints.
**Action:** Always wrap or attach tooltips (`CTkToolTip`) to icon-only buttons in Tkinter / CustomTkinter desktop applications.
