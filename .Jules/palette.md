## 2026-08-30 - Accessible Icon Buttons and Shortcut Hints in CustomTkinter UI
**Learning:** Icon-only action buttons (like `📸` and `🚀`) lack visual clarity and screen-reader accessibility for non-visual or keyboard users. Adding descriptive text labels and keyboard shortcut hints directly to buttons improves usability and spatial guidance.
**Action:** Always provide explicit text labels and key hints for action buttons in Tkinter / CustomTkinter desktop applications.
