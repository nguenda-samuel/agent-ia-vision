# Palette's Journal - Critical Learnings

## 2026-03-30 - QuickInput Accessibility and Keyboard Hints
**Learning:** Icon-only buttons (like `🚀` or `📸`) and modal windows in CustomTkinter lack immediate visual accessibility for keyboard navigation unless explicit helper text and tooltips/hints are present.
**Action:** Always provide explicit keyboard shortcut hints `(Entrée ↵ / Échap)` and clear descriptive tooltips for icon-only action buttons in desktop modal overlays.
